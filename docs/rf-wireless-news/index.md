# RF / Wireless 动态

本页按更新时间倒序归档 RF、SDR 与 wireless hack 相关的近期动态和新闻，并直接附上原始来源链接。

## 收录范围

- 行业新闻与公司动态；
- SDR、无线芯片和射频产品发布；
- 开源社区、项目生态与重要维护变化；
- 会议、竞赛、展会和研究社区事件；
- 频谱政策、无线监管与标准进展；
- 值得关注的无线安全事件；
- 其他会影响 SDR、RF 研究或 wireless hack 实践的新闻。

## 与 RF 原理精读的区别

- **RF / Wireless 动态**：看重时效性，回答“最近发生了什么、可能带来什么影响”。新闻可以偏行业、社区或产品，不要求都深入技术细节。
- **RF 原理精读**：看重长期学习价值，回答“某个经典理论或成熟工程概念如何被解释清楚”。内容不以最新为必要条件。

## 时间线

新的动态条目将从下一期四主题简报开始按日期倒序加入。每条将包含：

- 新闻或事件标题及原始链接；
- 简要背景；
- 为什么值得关注；
- 与 SDR、RF、无线研究、开源生态或 wireless hack 实践的关系。
