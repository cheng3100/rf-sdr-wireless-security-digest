# 软硬件一体项目

收录硬件主导并配套完整软件栈的 RF / SDR 项目，包括开源收发机、便携式平台、多通道阵列、FPGA gateware、设备固件、驱动和主机工具。

## 最新关注

- **HackRF 2026.01.3**：从 RF 前端、MCU/CPLD 到 USB host 软件均开放，是理解完整 SDR 系统边界的基础平台。
- **PortaPack Mayhem 2.4.0**：把 HackRF 扩展为带显示、控制、存储和设备端应用的便携 RF 平台。
- **Maia SDR**：基于 ADALM-Pluto 与 FPGA，提供高采样率实时瀑布图、Web 控制面和 SigMF IQ 录制。

详细分析见：[2026-08-01 周报](../weekly/2026-08-01.md)。
