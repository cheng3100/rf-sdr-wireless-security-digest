## 三、RF / Wireless 最新动态与新闻

### CVE-2026-16769
2026-09-08 公开，影响 Silicon Labs RS9116W/SiWx917。设备会处理本应受保护的未加密 pause-encryption request，无线范围内未认证攻击者可触发 DoS。

CVE 技术摘要：https://symaro.com/cve/cve-2026-16769.html
相关论文 Proteus：https://arxiv.org/abs/2409.02905

Proteus 是 protocol state-machine/property-guided fuzzing：不是只 mutate packet bytes，而是生成多数步骤合法、少量受控偏离的 message sequence，寻找状态转换与安全 property 逻辑漏洞。论文在 LTE/BLE 23 个设备上报告 25 个 unique issues、112 个实例。

本期最值得关注的 RF / Wireless 动态：CVE-2026-16769 与 Proteus 的 state-machine fuzzing → CVE 落地链路。

## 四、会议 / 活动高质量研究

### USENIX Security ’26：PrivacyShield — Relaying BLE Beacons to Counter Unsolicited Tracking
具体 Session：https://www.usenix.org/conference/usenixsecurity26/presentation/hofhammer
论文：https://francozappa.github.io/publication/2026/pshield/paper.pdf
Artifact：https://github.com/HexHive/privacyshield

PrivacyShield 利用 offline finding BLE beacon 缺少足够位置真实性认证这一点，把 beacon 捕获后经网络分发到远端 ESP32 relay 重放，让第三方手机在错误地点上报 beacon，从而混淆 stalking tag 的位置。Artifact 包含 Flask relay server、AirGuard Android 修改、ESP32 relay firmware、Sniffle 相关实验代码和 Find My location report 工具。

研究链：BLE beacon → capture → network relay → ESP32 RF retransmission → crowdsourced location report → privacy effect。

本期最值得精读的会议 / 活动研究：PrivacyShield。

## 五、本期最值得精读的 RF 原理文章

### Wireless Pi：Design of a Low-SNR Receiver
原文：https://wirelesspi.com/design-of-a-low-snr-receiver/

文章以完整 OFDM receiver 串起 multipath、CFO、AWGN、coarse/fine synchronization、FFT、channel estimation/equalization、residual phase tracking 和 iterative decoding。关键工程直觉是：低 SNR 下同步误差会直接改变 channel estimator/equalizer/decoder 是否能收敛，因此 synchronization 不是孤立的前处理步骤。

建议实验：QPSK/OFDM + 固定 multipath，逐步降低 SNR 并加入 CFO，记录 sync metric、FFT constellation、channel estimate、EVM/BER，再比较一次性 CFO correction 与持续 residual phase tracking。

本期最值得精读的 RF 原理文章：Wireless Pi — Design of a Low-SNR Receiver。
