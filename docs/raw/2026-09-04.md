## 一、软件为主的 SDR / wireless hack 动向与新项目

### FISSURE：从 RF 工具集合向分布式 RF operations 平台演进

FISSURE（Frequency Independent SDR-based Signal Understanding and Reverse Engineering）当前主线已经明显不再只是“把多个 SDR 工具放进一个 GUI”。项目当前能力包括信号检测/分类、IQ 采集和操作、协议发现、packet crafting、fuzzing、漏洞测试、分布式 sensor node、RF emitter geolocation，以及与 TAK 的目标/告警/地图工作流整合。

GRCon26 的具体 talk “FISSURE: Tactical RF Operations and Situational Awareness with GNU Radio” 进一步说明其方向：把多个分布式 RF sensor 的 sensing、geolocation、artifact collection、target management 和 operator workflow 组合成统一平台。

核心架构可以理解为：SDR / RF sensor → GNU Radio / protocol tools → Sensor Node → HIPRFISR / central coordination → target / alert / geolocation / artifact → TAK / operator workflow。

这对 SDR 软件工程很有价值，因为重点已经从“单机 decoder”进入“多个 RF 数据源如何被协调、归档、定位和转化成可行动信息”。

项目入口：https://github.com/ainfosec/FISSURE
GRCon26 具体议题：https://events.gnuradio.org/event/28/contributions/859/

**本期最值得试用的软件项目：FISSURE。**

建议优先从本地 Dashboard + 单 Sensor Node 开始阅读，再看分布式节点和 TAK integration；研究与测试应只在授权频谱和合法环境中进行。

## 二、软硬件结合的 SDR / wireless hack 开源项目动向

### Meshtastic 2.8.0 Alpha：节点身份与 packet authentication 开始强化

Meshtastic 在 8 月底进入 2.8.0 Alpha。它仍然是基于 LoRa 的低功耗、离网 mesh，但这一轮变化已经不仅是新增板卡或 UI：2.8.0 Alpha 引入 public-key node identity 与 XEdDSA packet signing 等方向，同时继续覆盖 ESP32、nRF52、RP2040/RP2350 和 Linux 设备。

这让 Meshtastic 的学习价值从“LoRa mesh 怎么转发消息”进一步扩展为：LoRa PHY / modem → embedded firmware → mesh routing → node identity → message authentication → mobile/web/CLI client。

对于 wireless hack / protocol analysis，值得关注的是：身份和签名机制加入后，广播型 mesh 中哪些 metadata 仍然公开、哪些消息得到真实性保护，以及旧节点/新节点互操作的边界。

官方项目：https://github.com/meshtastic/firmware
项目主页：https://meshtastic.org/

**本期最值得关注的软硬件一体项目：Meshtastic 2.8.0 Alpha。**

## 三、RF / Wireless 最新动态与新闻

### DJI 无认证 Bluetooth DUML 接口：无线配置面可被近距离修改

8 月 24 日公开的 CVE-2026-78306 描述了一类很典型的“无线控制面越权”问题：部分 DJI drone 暴露未认证的 DUML command interface over Bluetooth。处于 Bluetooth 范围内的攻击者可修改 Wi-Fi SSID、PSK、MAC、regulatory country code、channel 等配置；公开 advisory 还指出可通过修改 PSK 再连接内部 Wi-Fi，以及通过重启/禁用 Wi-Fi 或 Bluetooth 造成控制、视频和 telemetry 链路中断。

这条漏洞值得从系统链理解：Bluetooth radio → unauthenticated DUML command → Wi-Fi configuration → internal network reachability / control-link availability。

它提醒我们：无线安全不一定发生在 PHY decoder 本身，低权限/近距离 radio interface 如果能修改另一条无线链路的控制参数，同样可能形成跨协议攻击路径。

具体 advisory：https://github.com/advisories/ghsa-vq46-xr65-w8q7

### GRCon26 具体 technical program 已经非常完整

GRCon26 将于 9 月 21–25 日举行。当前具体 program 已经出现大量值得后续逐条跟踪的条目，包括 OpenWiFi + mmWave radar 的 ISAC 框架、低成本多天线 SDR、USRP/RFNoC FPGA workshop、分布式 coherent array synchronization，以及 Remote ID spoofing detection。

其中 “Detecting Falsified UAV Telemetry: An SDR Approach to Remote ID Spoofing Detection” 明确把未加密 Remote ID 广播视作 spoofing/falsified-data injection 的攻击面，是后续很值得追踪 paper/slides 的项目。

具体议题：https://events.gnuradio.org/event/28/contributions/887/

## 四、会议 / 活动高质量研究

### USENIX Security ’26：TrojPix — Electromagnetic Covert Channels via Imperceptible Pixel Modulation

**具体 session：** https://www.usenix.org/conference/usenixsecurity26/presentation/zhang-guoming

**论文 PDF：** https://www.usenix.org/system/files/conference/usenixsecurity26/sec26_prepub_zhang-guoming.pdf

TrojPix 研究的是一种非常典型的“没有无线协议却产生 RF covert channel”的问题。作者发现，通过对显示画面做肉眼难以察觉的 pixel modulation，可以在数字视频线缆上确定性地产生可控电磁辐射，无需系统权限，也不需要改硬件。

研究链路是：pixel pattern → digital video signalling → cable electromagnetic emission → RF capture → pixel-to-sample mapping / adaptive decoding → covert data channel。

作者在 9 个商用显示器品牌和 15 种数字视频线缆上验证了该方法，并报告最高 8.1 Mbps 的吞吐与 208 m 的最大距离；同时演示 fake screen-off 和 foreground embedding 两种模式。

这项工作对 SDR / wireless hack 的长期价值非常高，因为它说明“显示器/线缆”本身可以被当成一个非预期 RF transmitter。研究方式也很典型：先寻找可控的物理泄漏源，再建立调制映射，最后用 RF receiver 和自适应解码恢复数据。

**本期最值得精读的会议 / 活动研究：TrojPix。**

## 五、本期最值得精读的 RF 原理文章

### PySDR：Filters

原文：https://pysdr.org/content/filters

这一章适合作为前几期 Pulse Shaping、Synchronization 和 RDS end-to-end 之后的补基础。它从 low-pass / high-pass / band-pass / band-stop 开始，进一步解释 FIR、impulse response、convolution、filter taps，以及实时 streaming 时为什么不能把每个 chunk 完全独立过滤。

最值得建立的工程模型是：输入 IQ → FIR taps / impulse response → convolution → filtered IQ。对于长度为 M 的 FIR，每个输出 sample 都依赖当前及之前的输入，因此当实时 IQ 被拆成多个 buffer 时，filter state 必须跨 buffer 保留；否则每个 chunk 开头都会因为缺少之前的 M-1 个 sample 出现错误或瞬态。

这直接对应真实 SDR driver / userspace pipeline：USB/DMA 每次送来的 buffer 是离散的，但 DSP filter 的数学状态是连续的。

建议实验：生成 tone + noise，先整段 FIR filtering；再把输入切成固定大小 chunks，故意不保存 filter state，观察 chunk boundary spur/glitch；最后用带 state 的 streaming FIR 恢复与整段过滤一致的输出。

**本期最值得精读的 RF 原理文章：PySDR — Filters。**

它把数学上的 convolution 直接连接到了工程中的实时 IQ buffer / streaming state，是非常值得从 Linux/驱动视角理解的一章。
