# RF / SDR / Wireless Security Digest

这是一个持续更新的 RF、SDR 与无线安全研究技术情报库，目标是把每周资讯沉淀为可检索、可复用、可长期维护的在线书籍。

## 内容结构

### 软件型开源项目

以软件实现为主，包括 SDR 客户端、频谱与瀑布图工具、解调/分析软件、协议逆向工具、GNU Radio 模块、SoapySDR 生态、URH、rtl_433、FISSURE、SigMF 工具链、驱动和固件工具。

### 软硬件一体项目

硬件主导并配套完整软件栈，包括 HackRF 类开源 SDR、便携式 RF 平台、阵列、探针、扩展板、固件与主机工具组合。

### 其他长期主题

- BLE、Wi-Fi、Sub-GHz、LoRa、Zigbee、Thread、NFC/RFID、GNSS 等无线安全研究；
- 高质量 RF / SDR 原理文章、论文、博客与演讲；
- 协议逆向案例与实验方法；
- 面向自有设备、屏蔽环境和合法授权场景的实践实验。
