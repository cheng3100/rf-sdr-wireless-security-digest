# 2026-07-31 · 第 1 期

## 一、软件为主的 SDR / wireless hack 动向与新项目

### URH-NG

经典 Universal Radio Hacker 仓库归档后，URH-NG 成为值得持续观察的继任方向。重点关注新版 Python/Qt 兼容性、大型 IQ 文件处理、自动调制识别、CRC 搜索、whitening 与协议字段比较能力。

**适用方向：** OOK、FSK、GFSK 与专有 Sub-GHz 协议逆向。

### RF-Swift

面向 RF 工具链的隔离部署环境，适合解决 GNU Radio、Python、SoapySDR 和设备驱动之间的依赖冲突。

**适用方向：** 建立可复现的 PC / Raspberry Pi 无线实验环境。

### SDROxide

Rust 编写的新型 SDR 客户端，值得从实时 IQ 缓冲、DSP pipeline、线程模型与内存管理角度阅读。

**适用方向：** SDR 客户端工程、实时数据面与 Rust 系统软件。

### Intercept

将多种 SDR decoder 聚合进统一 Web 界面，体现频谱观察、信号发现、协议识别和解码工作流一体化的趋势。

### FISSURE

综合 RF 研究框架，覆盖信号检测、分类、协议发现、IQ 操作、packet crafting 与数据集构建。建议作为中后期综合平台，而不是入门第一步。

### Kismet

适合作为 Wi-Fi、Bluetooth、Zigbee 与其他 RF 数据源的被动侦测、设备聚合和 WIDS 平台。

**本期最值得试用的软件项目：RF-Swift。**

## 二、软硬件结合的 SDR / wireless hack 开源项目动向

### 可移动 RF Capture System

由 HackRF One、Raspberry Pi 5、GNSS 与高速 SSD 组成的便携 IQ 采集节点，重点涉及 USB streaming、持续写盘、SigMF 元数据和 buffer underrun 监控。

### OpenWXSDR

将 RTL-SDR / Airspy 与 Raspberry Pi 或 x86 Linux 组合成自动化 radiosonde 接收站，涉及多 SDR 并行接收、自动扫描、任务调度与长期无人值守运行。

### Open.Space

低成本、可拼接的 SDR 相控阵方向，适合学习多通道相位同步、阵元校准、数字波束形成与时钟一致性。

**本期最值得关注的软硬件一体项目：可移动 RF Capture System。**

## 三、本期最值得精读的 RF 原理文章

### PySDR：IQ Sampling

重点理解：

- 为什么 SDR 输出复数 IQ；
- 复基带带宽与采样率的关系；
- 负频率的含义；
- I/Q 幅相不平衡与镜像抑制；
- 下变频后 IQ 文件中为何不再保留原始 RF 载波。

### PySDR：Digital Modulation

重点理解 symbol 与 bit 的关系、星座旋转、频偏、定时偏差、多径，以及 carrier recovery 与 timing recovery 的必要性。

### Wireless Pi：Synchronization

重点理解频偏为何表现为 IQ 平面持续旋转，以及 Costas loop、相位差估计和定时恢复的作用。

**本期最值得精读的 RF 原理文章：PySDR 的 IQ Sampling。**
