## 一、软件为主的 SDR / wireless hack 动向与新项目

### [FISSURE：从 RF 工具集合向分布式 RF operations 平台演进](https://github.com/ainfosec/FISSURE)

FISSURE（Frequency Independent SDR-based Signal Understanding and Reverse Engineering）当前主线已经明显不再只是“把多个 SDR 工具放进一个 GUI”。项目当前能力包括信号检测/分类、IQ 采集和操作、协议发现、packet crafting、fuzzing、漏洞测试、分布式 sensor node、RF emitter geolocation，以及与 TAK 的目标/告警/地图工作流整合。

[GRCon26 具体 talk：FISSURE: Tactical RF Operations and Situational Awareness with GNU Radio](https://events.gnuradio.org/event/28/contributions/859/) 进一步说明其方向：把多个分布式 RF sensor 的 sensing、geolocation、artifact collection、target management 和 operator workflow 组合成统一平台。

核心架构可以理解为：SDR / RF sensor → GNU Radio / protocol tools → Sensor Node → HIPRFISR / central coordination → target / alert / geolocation / artifact → TAK / operator workflow。

**本期最值得试用的软件项目：FISSURE。**

## 二、软硬件结合的 SDR / wireless hack 开源项目动向

### [Meshtastic 2.8.0 Alpha](https://github.com/meshtastic/firmware)

Meshtastic 在 8 月底进入 2.8.0 Alpha。它仍然是基于 LoRa 的低功耗、离网 mesh，但这一轮变化已经不仅是新增板卡或 UI：2.8.0 Alpha 引入 public-key node identity 与 XEdDSA packet signing 等方向，同时继续覆盖 ESP32、nRF52、RP2040/RP2350 和 Linux 设备。

学习链路可以扩展为：LoRa PHY / modem → embedded firmware → mesh routing → node identity → message authentication → mobile/web/CLI client。

**本期最值得关注的软硬件一体项目：Meshtastic 2.8.0 Alpha。**

## 三、RF / Wireless 最新动态与新闻

### [DJI 无认证 Bluetooth DUML 接口：CVE-2026-78306](https://github.com/advisories/ghsa-vq46-xr65-w8q7)

8 月 24 日公开的 CVE-2026-78306 描述了一类典型的“无线控制面越权”问题：部分 DJI drone 暴露未认证的 DUML command interface over Bluetooth。处于 Bluetooth 范围内的攻击者可修改 Wi-Fi SSID、PSK、MAC、regulatory country code、channel 等配置；公开 advisory 还指出可通过修改 PSK 再连接内部 Wi-Fi，以及通过重启/禁用 Wi-Fi 或 Bluetooth 造成控制、视频和 telemetry 链路中断。

攻击链可以概括为：Bluetooth radio → unauthenticated DUML command → Wi-Fi configuration → internal network reachability / control-link availability。

### [GRCon26：Remote ID spoofing detection](https://events.gnuradio.org/event/28/contributions/887/)

GRCon26 当前 technical program 已出现 OpenWiFi + mmWave radar ISAC、低成本多天线 SDR、RFNoC FPGA workshop、分布式 coherent array synchronization，以及 Remote ID spoofing detection 等具体议题。其中该 Remote ID 研究明确把未加密广播视作 spoofing/falsified-data injection 的攻击面，后续值得继续追踪 paper/slides。

**本期最值得关注的 RF / Wireless 动态：DJI Bluetooth DUML 漏洞。**

## 四、会议 / 活动高质量研究

### [USENIX Security ’26：TrojPix — Electromagnetic Covert Channels via Imperceptible Pixel Modulation](https://www.usenix.org/conference/usenixsecurity26/presentation/zhang-guoming)

**论文 PDF：** [sec26_prepub_zhang-guoming.pdf](https://www.usenix.org/system/files/conference/usenixsecurity26/sec26_prepub_zhang-guoming.pdf)

TrojPix 研究一种没有无线协议却能产生 RF covert channel 的路径：通过肉眼难以察觉的 pixel modulation，在数字视频线缆上确定性地产生可控电磁辐射，无需系统权限，也不需要修改硬件。

**研究链路：** pixel pattern → digital video signalling → cable electromagnetic emission → RF capture → pixel-to-sample mapping / adaptive decoding → covert data channel。

作者在 9 个商用显示器品牌和 15 种数字视频线缆上验证，并报告最高 8.1 Mbps 吞吐与 208 m 最大距离，同时演示 fake screen-off 与 foreground embedding 两种模式。

**本期最值得精读的会议 / 活动研究：TrojPix。**

## 五、本期最值得精读的 RF 原理文章

### [PySDR：Filters](https://pysdr.org/content/filters)

这一章从 low-pass / high-pass / band-pass / band-stop 开始，进一步解释 FIR、impulse response、convolution、filter taps，以及实时 streaming 时为什么不能把每个 chunk 完全独立过滤。

最值得建立的工程模型是：输入 IQ → FIR taps / impulse response → convolution → filtered IQ。对于长度为 M 的 FIR，每个输出 sample 都依赖当前及之前的输入，因此当实时 IQ 被拆成多个 buffer 时，filter state 必须跨 buffer 保留；否则每个 chunk 开头都会因为缺少之前的 M-1 个 sample 出现错误或瞬态。

这直接对应真实 SDR driver / userspace pipeline：USB/DMA 每次送来的 buffer 是离散的，但 DSP filter 的数学状态是连续的。

建议实验：生成 tone + noise，先整段 FIR filtering；再把输入切成固定大小 chunks，故意不保存 filter state，观察 chunk boundary spur/glitch；最后用带 state 的 streaming FIR 恢复与整段过滤一致的输出。

**本期最值得精读的 RF 原理文章：PySDR — Filters。**
