## 一、软件项目

### [radiom](https://github.com/thepacket/radiom)
2026 年出现的移动 SDR 应用方向，可连接 KiwiSDR、OpenWebRX 和 RTL_TCP，并在统一界面中整合大量协议 decoder。仓库说明当前已集成约 88 个解码器，复用了 fldigi、WSJT-X 系、multimon-ng、direwolf、dumphfdl、JS8Call 等生态。

**价值：** 值得研究远程 SDR source、协议解码、移动 UI 与网络访问如何组合成长期运行的软件工作台。

### [Radio-FM](https://arxiv.org/abs/2608.05793)
2026 年 8 月提交的 RF foundation model，直接从原始 I/Q 学习通用表示，并覆盖 modulation、radar、emitter identification、wireless technology recognition 和 interference identification 等任务。

**本期最值得试用的软件项目：radiom。**

<a id="hardware-software"></a>
## 二、软硬件项目

### [Pocket SDR v0.19](https://github.com/tomojitakasu/PocketSDR)
开源多通道 GNSS SDR，包含 2/4/8 通道 RF frontend、IF 采集和 Python/C/C++ 接收机。v0.19 加入 Galileo E1 CBOC / E5 AltBOC 等多级副载波 replica 的 int8 correlator 支持，并增强低 C/N0 acquisition/tracking、pilot extended coherent tracking 和多 stream 输出。

**适用：** GNSS L1（约 1525–1610 MHz）及 L2/L5/L6（约 1160–1290 MHz）。适合从 RF frontend → ADC/IF → correlator → acquisition/tracking → navigation message → PVT 完整学习。

### [HackRF 主线](https://github.com/greatscottgadgets/hackrf)
稳定版仍为 2026.01.3，但主线持续推进 radio configuration mode、固定点中心频率/采样率、radio register locking、transceiver temperature 等 HackRF Pro 能力。

**本期最值得关注的软硬件一体项目：Pocket SDR v0.19。**

## 三、RF / Wireless 动态

### Wi-Fi beamforming feedback 被用于无摄像头人体识别
8 月 18 日公开报道的一项研究显示，普通 Wi-Fi 基础设施中的 beamforming feedback 可以被用于人体识别；报道描述的实验在 197 名参与者上取得接近 100% 的识别率，而且不要求被识别者自己携带主动设备。

**意义：** 原本用于链路优化的 PHY/CSI 类反馈正在变成隐私侧信道，后续 802.11bf 等 Wi-Fi sensing 标准的隐私边界值得持续跟踪。

### [FCC：Unleashing Unlicensed Spectrum for Direct-to-Device](https://www.fcc.gov/document/fcc-looks-expand-d2d-satellite-connectivity-unlicensed-wireless)
FCC 在 2026-08-06/07 推进 FCC-26-51 / ET Docket 26-169，探索允许部分 Part 15 非授权频段设备与获授权卫星直接通信，并讨论非授权设备在 spacecraft 中的使用。

**本期最值得关注的 RF / Wireless 动态：Wi-Fi beamforming feedback 的隐私侧信道化。**

## 四、会议 / 活动高质量研究

### BLERP：BLE Re-Pairing Attacks and Defenses

**具体研究页：** [NDSS — BLERP](https://www.ndss-symposium.org/ndss-paper/blerp-ble-re-pairing-attacks-and-defenses/)

**论文 PDF：** [2026-f121-paper.pdf](https://www.ndss-symposium.org/wp-content/uploads/2026-f121-paper.pdf)

**Slides PDF：** [f0121-sacchetti-slides.pdf](https://www.ndss-symposium.org/wp-content/uploads/f0121-sacchetti-slides.pdf)

**Black Hat Asia 2026 研究团队条目：** [EURECOM — Exploiting BLE re-pairing with the BLERP attacks](https://www.eurecom.fr/en/publication/8697?slug=exploiting-ble-re-pairing-with-the-blerp-attacks)

研究针对 BLE re-pairing 的信任边界：标准允许已配对设备重新协商并覆盖长期配对密钥，研究发现未认证 re-pairing、安全级别 downgrade 等设计问题，可导致 Central/Peripheral impersonation 和单/双通道 MitM。

作者实现 BLERP toolkit，使用低成本 **nRF52** + **Mynewt / NimBLE / Scapy** 做 OTA pairing/re-pairing 和端到端 MitM，在 22 个目标设备上评估。

**研究链路：** BLE pairing/session establishment → re-pairing trust boundary → key overwrite/downgrade → nRF52 OTA tool → impersonation/MitM → mitigation。

**本期最值得精读的会议 / 活动研究：BLERP。** 资料链完整：独立研究页、paper、slides、演讲和可复现实验工具都可以串起来。

## 五、RF 原理精读

### [PySDR：End-to-End Example with RDS](https://pysdr.org/content/rds.html)
该章节把真实 FM 广播中的 RDS 解码完整串起来：IQ acquisition → FM demod → frequency shift → filtering → decimation/resampling → symbol timing → fine frequency sync → BPSK demod → bit/byte parsing。

它适合作为 IQ Sampling、Link Budget、Synchronization 之后的整链路练习，重点观察不同 DSP block 的顺序、采样率转换和同步状态如何共同决定最终协议 decode。

**建议实践：** 使用章节提供的 IQ 数据，先画每一级输出；再故意改变 frequency offset、filter bandwidth、resampling ratio 或 timing 参数，观察错误如何传递到最终 bit decode。

**本期最值得精读的 RF 原理文章：PySDR — End-to-End Example with RDS。**
