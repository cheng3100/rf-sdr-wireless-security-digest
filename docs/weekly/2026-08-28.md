## 一、软件为主的 SDR / wireless hack 动向与新项目

### [AetherSDR v26.8.4](https://github.com/aethersdr/AetherSDR/releases/tag/v26.8.4)

**本期最值得试用的软件项目：AetherSDR v26.8.4。** 它已经是可直接运行的软件，且本期更新非常适合观察“多 radio backend + 网络协议 + DSP/UI 状态机”；GNU Radio 4 更适合作为中长期框架演进跟踪对象。

## 三、RF / Wireless 最新动态与新闻

### [BlueZ：A2DP stream endpoint 栈溢出 — ZDI-26-589 / CVE-2026-19774](https://www.zerodayinitiative.com/advisories/ZDI-26-589/)
Zero Day Initiative 在 2026-08-24 公布该漏洞。BlueZ 对 A2DP stream endpoint 中用户可控长度缺少充分校验，复制到固定长度栈 buffer 时产生溢出。攻击者需要先让恶意 Bluetooth 设备与目标完成 pairing，但成功后可能在 bluetoothd/root 上下文执行代码；BlueZ 已提供修复。

### BlueZ：EIR discovery 路径栈溢出 — CVE-2026-80186
2026-08-25 公开的另一个 BlueZ stack-based buffer overflow 位于设备 discovery 的 Extended Inquiry Response（EIR）处理。攻击者处于 Bluetooth 无线范围内即可发送精心构造的 EIR packet；公开描述指出可导致 bluetoothd 崩溃，并可能达到代码执行。参考：[Snyk advisory](https://security.snyk.io/vuln/SNYK-DEBIAN11-BLUEZ-19268263)。

两条漏洞放在一起很有代表性：一个位于 pairing 后的 A2DP profile parser，另一个位于 discovery/EIR 元数据路径。对 Linux wireless stack 安全分析，HCI event、EIR/AD parser 和 profile parser 都应纳入 OTA fuzzing 与内存安全审计范围。

**本期最值得关注的 RF / Wireless 动态：BlueZ 在一周内连续暴露两条 Bluetooth 栈内存安全攻击面。**

## 四、会议 / 活动高质量研究

### [USENIX Security ’26：Injected and Leaked — Actively Inducing Side-Channel Leakage Using Electromagnetic Injection and Hardware Nonlinearity](https://www.usenix.org/conference/usenixsecurity26/presentation/yan-haoran)

**论文 PDF：** [usenixsecurity26-yan-haoran.pdf](https://www.usenix.org/system/files/usenixsecurity26-yan-haoran.pdf)

这项研究把传统上分开的 EM injection 与 EM side-channel leakage 连接起来：作者研究能否通过主动注入 RF，让原本难以观测的低频秘密被硬件非线性搬移到更容易远距离接收的电磁频段。放大器、ADC、电源转换器等非线性器件会把低频 secret signal 与外部注入 RF carrier 混频/调制，形成新的可观测频谱分量。

作者设计 InjectEave，并展示使用可获得的 RF equipment 对有线和无线耳机正在播放的音频进行远距离窃听，实验距离达到约 30 m，并包含穿墙场景；同时分析智能家居功耗、模拟传感器输入等低频秘密的 injection-induced leakage，以及固定电话闭环窃听/操纵案例。

**研究链路：** RF injection → hardware nonlinearity → low-frequency secret 被上变频/调制到泄漏载波 → RF receiver 捕获 → signal processing / recovery → eavesdropping 或 closed-loop manipulation。

这类研究的重要性在于它不是攻击某个标准无线协议，而是利用 mixed-signal hardware 的模拟非理想性建立隐蔽 RF 信道。SDR/RF equipment 在其中承担频谱观察、信号捕获、频率扫描和恢复，而漏洞根因位于真实硬件。

**本期最值得精读的会议 / 活动研究：Injected and Leaked。**

## 五、本期最值得精读的 RF 原理文章

### [PySDR：Pulse Shaping](https://pysdr.org/content/pulse_shaping)
该章系统解释 pulse shaping、ISI、matched filter、raised-cosine/root-raised-cosine（RC/RRC）、roll-off factor、eye diagram，并进一步联系 OQPSK 与 MSK。

核心链路是：离散 symbol → 上采样 → Tx RRC pulse shaping → channel/noise → Rx matched RRC → timing recovery → symbol sampling。矩形 symbol 会产生很宽频谱，而随便低通又会引入 ISI；Nyquist pulse-shaping 的关键是让其他 symbol 的 pulse 在目标采样时刻恰好过零，从而允许时域重叠但不在理想判决点产生 ISI。

Tx/Rx 各使用一个 RRC，级联后形成整体 RC 响应；接收端 matched filter 同时帮助在 AWGN 下最大化采样点 SNR。roll-off β 则直接体现频谱占用与时域脉冲长度之间的折中。

与 SDR 捕获/解调的关系：抓到 PSK/QAM IQ 后，如果 matched filter、samples-per-symbol、symbol timing 或 roll-off 假设错误，星座会扩散、eye 会闭合，即使 CFO 已校正也可能无法稳定判决。因此 pulse shaping 是理解 timing recovery 的前置知识，而不仅属于发射机。

推荐实验：用 Python 或 GNU Radio 生成 BPSK/QPSK，固定 SNR 后依次改变 β、Rx matched-filter 参数与 sampling instant，同时观察 PSD、eye diagram 和 constellation。

**本期最值得精读的 RF 原理文章：PySDR — Pulse Shaping。**
