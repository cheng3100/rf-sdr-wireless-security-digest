# 编写与归档规范

## 每周文件命名

使用 `docs/weekly/YYYY-MM-DD.md`。

## 固定章节

1. 软件型开源项目；
2. 软硬件一体项目；
3. 无线安全研究；
4. RF / SDR 原理精读；
5. 可执行的小实验；
6. 本期优先级。

## 项目筛选字段

每个项目至少记录：项目用途、技术亮点、适用频段/协议/硬件、软件栈、开源状态、活跃度、安装与复现成本、是否值得试用。

## 来源优先级

项目仓库与 release notes、论文、会议演讲、作者博客、高质量独立技术分析。避免营销软文、泛泛新闻和重复转载。

## 安全边界

无线安全内容以防御性研究和合法授权场景为前提，不提供针对真实目标的未授权攻击步骤。
